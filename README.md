# Aseconvir — Landing Page V2

Segunda versión de la landing page para el proyecto académico **Aseconvir**. Mejora y refina el diseño, la estructura y la experiencia de usuario respecto a la [V1](https://github.com/Sneider4/landing-aseconvir-one).

![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

**[▶ Ver demo en vivo](https://sneider4.github.io/landing-aseconvir-two/)**

## Características

- Estructura HTML5 semántica mejorada respecto a V1
- Navegación interactiva con JavaScript vanilla
- Navbar con comportamiento dinámico (scroll / responsive)
- Diseño visual refinado y mejor organización del contenido

## Estructura del proyecto

```
landing-aseconvir-two/
├── index.html          # Página principal
├── script.js           # Lógica general de la página
├── script-navbar.js    # Comportamiento del menú de navegación
└── img2.png            # Imagen principal
```
